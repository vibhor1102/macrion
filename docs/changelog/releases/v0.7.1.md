# Macrion 0.7.1

## Bug Fixes & Refinements

- Improve stability when using floating controls during scenario playback.
- Retry interrupted touch actions once, and pause playback if a touch action cannot be confirmed.
- Make Pause and Stop more reliable while scenarios and action tests are starting.
- Keep sound actions in order and improve responsiveness when loading sounds or image previews.

## Installation

Download `arm64-v8a` for most modern phones, or the universal APK if unsure.
