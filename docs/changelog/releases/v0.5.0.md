# Macrion 0.5.0

## Modernized Interface

- Complete the XML-to-Jetpack Compose migration: Macrion’s interface is now fully native Jetpack Compose.
- Give overlay menus consistent rounded corners for a more cohesive, modern appearance.
- Update icons throughout the app to Material Symbols Rounded, with subtle refinements to their shapes and visual balance.

## Refreshed Settings

- Refresh and modernize the Settings layout, organizing controls into clear categories.
- Introduce an Advanced settings section. Its first option lets you raise the maximum configurable tolerated difference for image and other supported conditions from 20% to as much as 50%.
- Add an About section showing the installed version number and installation source.

## Action and Condition Carousels

- Swipe through multiple cards with a single fast flick.
- Reorganize the button layout to make each control’s purpose clearer.
- Move reordering into its own menu, accessible through the ⇅ icon.

## Customizable Floating Toolbar

- Resize the toolbar from 50% to 150%, with a live preview.
- Automatically hide the toolbar while no scenario is running. Auto-hide is enabled by default after two minutes; disable it or choose a delay from three seconds to ten minutes in Settings.

## Bug Fixes & Refinements

- Preview images, colors, text, numeric comparisons, and trigger details directly from the report’s Conditions and Timeline tabs.
- Replace RGB color-editing sliders with hue, saturation, and brightness controls.
- Improve drag-and-drop reordering with clearer feedback and easier dragging from the reorder handle.
- Improve light and dark theme consistency across icons, text, and borders.
- Keep overlay editors usable when the keyboard opens and improve layout handling during screen rotation.
- Improve report fast scrolling and scrollbar behavior.
- Improve notification text readability and reduce truncation.
- Remember external “Run current scenario” requests received while the screen-capture permission prompt is awaiting acceptance, so the scenario runs immediately once accepted.
- Keep external-action choices current while editing scenarios, and add clearer broadcast guidance and a documentation shortcut.
- Handle accessibility-service loss and scenario shutdown more reliably.
- Remove premature empty-state flashes from scenario and overlay lists.
- Correct remaining unintended Klick’r references to Macrion.

## Known Issues

- Scrolling in some menus can cause lag or dropped frames.
- Most tutorials are currently broken, and their spotlight highlights do not appear correctly.
- Documentation has not yet been updated for features added in v0.5.
