# Macrion 0.6.3

## Bug Fixes & Refinements

- Fix Add and Copy buttons becoming unresponsive when switching between screen and trigger events.
- Preserve unsaved action and condition order changes and discard confirmations when rotating the device.
- Preserve numeric input across rotation, including new counter starting values.
- Reject invalid and overflowing numeric entries instead of silently saving the previous value.
- Prevent overlay buttons becoming unresponsive after rotating the device immediately after a tap.
- Correct preview animation timing for very long pauses and swipes.
