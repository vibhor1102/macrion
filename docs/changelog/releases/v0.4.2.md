# Macrion 0.4.2

## Bug Fixes & Refinements

- Fixed scenario-configuration overlays on Android 9 and earlier, including affected Samsung and Lenovo devices.
- Color-condition recapture now keeps the previously selected pixel in place.
- Fixed text-recognition model downloads to use Macrion's model release and reject unsafe archive contents.
- Restricted notification actions to Macrion for safer, more reliable handling.
- Updated dependencies; unforeseen compatibility issues are unlikely but possible.
- Prepared Macrion for its F-Droid release.
